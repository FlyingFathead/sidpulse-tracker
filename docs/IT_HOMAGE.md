# An homage to Impulse Tracker

SIDpulse Tracker is an homage to Impulse Tracker. Schism Tracker provides the
primary modern reference for its keyboard behavior, dense editor layout,
function-key pages and practical refinements. SIDpulse is a new Python/pygame-ce
implementation, not a literal Schism source fork.

Preserve the keyboard, cursor and block-editing habits. Replace the musical
internals with actual SID instruments, chip register semantics and ultimately a
C64 export compiler. The workstation is modern; the synthesizer is SID-native.

The GUI uses independently rendered scalable text and layout metrics, so a
familiar tracker does not require an unreadably small historical framebuffer.
The first review target is the feel under the fingers, before sequencing and
the exporter become large enough to make core interaction mistakes expensive.
