# Apply the v0.2.26 update

Close the tracker and keep a copy of the current source directory. Extract the
incremental archive into the parent of the existing `sidpulse-tracker/` folder
and allow replacement. Review local source edits before overwriting them.

The incremental archive is for v0.2.25 and works with either version of its
launcher wording. It includes the final two-line console warning. The full ZIP
contains all tracked source files; use that for an older installation or a new
checkout. Both extract under `sidpulse-tracker/`. No deletions or dependency
changes are required. SHA256SUMS-v0.2.26.txt verifies both archive files.

Modern keyboard mapping is the default after upgrading. To keep the previous
Ctrl+Insert roll shortcut, select Settings Menu > Keyboard mapping > Classic.
Existing .sidpulse files and PW sweep demonstration files need no replacement.
