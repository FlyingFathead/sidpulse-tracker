# v0.2.33 validation evidence

See `docs/PERFORMANCE-v0.2.33.md` for the measurement method and limits.
The two performance JSONL files hold 150 serial trials, including 42 live
trials. Native comparison hashes cover seven songs. Emulator measurements use
VICE 3.7.1 classic reSID; hit windows isolate the PCM contribution to HERMO.ROM.
The regression summary distinguishes the broad run from corrective reruns.

Screenshots show F3 sample tools, the volume dialog, synthesis slot selection,
and frozen/unfrozen F4 provenance at 640×480, 960×1080 and 1280×900. These are
test copies of the project; the source project has not been modified.

The separate C64 test archive contains model/clock-labelled PRGs, raw emulator
WAV recordings and explicitly gain-adjusted MP3 listening previews.
