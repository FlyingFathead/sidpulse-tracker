# Reference samples

These synthesizer-generated kick and snare samples were supplied by the project author for inclusion as royalty-free reference sounds.

- `sidpulse_sample_synthwave_kick.wav`
- `sidpulse_sample_synthwave_snare.wav`

The supplied 48 kHz, 16-bit mono WAV data is unchanged. Open F3, choose a sample slot and Import to load one. Auto-squeeze is enabled by default; turn it off to keep the original PCM resolution. Use Synthesize audio to fit an ordinary SID instrument, or map a PCM sample to an instrument for experimental digi playback.

Synthesized SID instruments approximate the source. Keep these WAV files as references when comparing fits and squeeze settings.
